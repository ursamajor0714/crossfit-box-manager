# CrossFit Grove — 박스 운영 관리 시스템

크로스핏 박스 한 곳에서 **실제로 매일 쓰고 있는** 관리 도구입니다.
회원 등록부터 계약서 작성, 락커 배정, 수업 시간표, 매출·가계부까지 운영에 필요한 것을 한 화면에서 처리합니다.

> 이 저장소는 **공개용 사본**입니다.
> 운영 DB 접속 정보와 배포 설정은 제거했고, 회원 데이터는 전부 지어낸 목업으로 대체했습니다.
> 구조와 코드만 볼 수 있습니다.

## 스택

Node.js · Express 5 · PostgreSQL (`pg`) · EJS · ExcelJS

프레임워크를 얹지 않고 Express + EJS + 바닐라 JS로 만들었습니다.
운영자 한 명이 쓰는 도구라 빌드 단계 없이 파일만 올리면 배포되는 쪽이 유지보수가 쌌습니다.

## 화면

| 경로 | 쓰는 사람 | 내용 |
|---|---|---|
| `/` | 방문자 | 소개, 공지, 오늘의 WOD, 체험·방문 신청 |
| `/admin` | 사장님·코치 | 회원·계약·락커·시간표·매출·가계부·문자 |
| `/contract` | 태블릿 | 현장 계약서 작성 (서명·사진 촬영 포함) |
| `/member` | 회원 | 내 회원권, 홀딩 신청, 받은 쪽지 |
| `/visit` | 방문자 | 체험 수업 신청 |
| `/wod-builder` | 코치 | WOD 작성 |

## 기능

- **회원** — 등록·재등록, 기간제/횟수권, 홀딩(신청→승인), 특별 연장, 휴면, 보충자료(사진·부상·목표)
- **계약서** — 태블릿 현장 작성, 서명 캡처, 작성 즉시 회원 등록으로 연결
- **락커** — 152칸 배치도, 배정·연장·해지 이력
- **수업** — 요일별 템플릿을 실제 수업으로 펼치고, 개별 수업만 취소 가능
- **매출·가계부** — 등록·락커·드롭인 매출 자동 집계 + 수기 입출금, 고정비 월 반복, 엑셀 내보내기
- **문자** — 템플릿 기반 발송(알리고), 발송 이력
- **권한** — 코치(부운영자) 계정에 화면 단위 열람 권한 부여

## 구조

```
backend/
  server.js        Express 앱
  db.js            PG 연결 + 스키마 정의(24개 테이블) + 초기 시딩
  routes/          기능별 라우트 17개
  middleware/      관리자·계약서·회원 토큰 인증
  permissions.js   코치 권한 트리
  utils/           날짜(KST), 비밀번호(scrypt), 가계부 고정비 전개, 문자 발송
  scripts/
    seed-demo.js   데모용 목업 데이터
frontend/views/    EJS 화면
docs/              작업 기록 (기능별 결정 사항과 검사 결과)
```

## 실행

Postgres 하나만 있으면 됩니다.

```bash
docker run -d --name grove-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=grove -p 55432:5432 postgres:16-alpine

cp .env.example .env
npm install
node backend/scripts/seed-demo.js --reset
npm start
```

`http://localhost:3000` 접속.

| 로그인 | 방법 |
|---|---|
| 관리자 | `.env` 의 `ADMIN_PASSWORD` (기본 `changeme`) |
| 회원 | 이름 + 전화번호 뒷 4자리 — 예: `이가입` / `0001` |
| 코치 | `김코치` / `1111` (회원 관리 권한), `박코치` / `2222` (가계부 권한) |

시드는 회원 12명, 계약서·홀딩·락커·수업·가계부·문자 이력을 넣습니다.
등록일과 결제일을 과거로 흩어 놓아서 **월별 매출·손익 화면이 여러 달에 걸쳐 채워집니다.**

## 구현 메모

기록해 둘 만한 판단 몇 가지입니다.

**이름 중복은 DB 유니크 인덱스로 막습니다.** 라우트에서 "있나 확인 → 없으면 넣기"로만 막았더니,
등록 버튼을 빠르게 세 번 누르면 셋 다 '없음'을 읽고 세 명이 만들어졌습니다.
회원 로그인이 이름 기준이라 이름은 원래 유일해야 했습니다.

**고정비는 한 건만 저장하고 조회할 때 펼칩니다.** 매달 같은 행을 쌓지 않고,
등록월부터 기준월까지 조회 시점에 생성합니다. 31일에 등록한 고정비가 2월에 존재하지 않는 날짜가
되던 문제는 그 달 말일로 당겨서 처리했습니다.

**시간은 전부 KST로 고정했습니다.** 서버가 UTC로 돌면 자정 근처에 날짜가 하루 밀려서
"오늘의 WOD"와 일별 매출이 어긋납니다.

**비밀번호는 scrypt로 해싱하되 평문 레거시도 검증합니다.** 초기에 평문으로 저장된 계정이 있어,
해시 접두사(`scrypt$`)로 구분해 양쪽을 모두 처리합니다.

**사진 중복 저장을 정리합니다.** 계약서로 회원 등록을 마치면 같은 사진이 계약서와 회원 양쪽에
남아서, 회원 쪽에 사진이 있는 완료 계약서는 사본을 비웁니다.

**성능·보안 보강은 규모를 기준으로 미뤘습니다.** 회원 수십 명 · 운영자 두 명 규모라
인덱스 튜닝과 2단계 인증은 넣지 않았습니다. 넣을 조건은 `docs/` 에 적어 두었습니다.

## 공개용 사본에서 제거한 것

- 운영 DB 접속 정보 (`.env`) → `.env.example` 로 대체
- 배포 설정 (`render.yaml`) 및 DB 마이그레이션 스크립트
- 사업자 정보·대표자 실명·연락처 → 예시 값으로 대체
- 실제 회원 데이터 → `seed-demo.js` 의 목업으로 대체
