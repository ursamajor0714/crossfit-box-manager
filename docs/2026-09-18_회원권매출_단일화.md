# 회원권 매출 이름 단일화 (2026-09-18)

## 문제

같은 돈을 두 이름으로 부르고 있었다.

- 회원이 회원권을 결제하면 매출에 **`회원등록`** 으로 자동으로 잡힌다
- 그런데 가계부에서 손으로 넣을 때의 항목 이름은 **`회원권`** 이었다

그래서 매출 구분 필터에 두 이름이 다 들어가 있었고, "회원권 매출이 얼마지" 하고 필터를 걸면
한쪽만 잡혔다. 같은 것을 두 번 셀 위험도 있었다.

## 결정

사용자 판단: **회원권 매출은 회원 등록에서 자동으로만 잡히게 하고, 가계부에서는 직접 입력하지 못하게 한다.**
이름은 `회원등록` 하나로 통일한다.

## 처리

1. 가계부 매출 항목에서 `회원권` 제거 → **락커 · 드랍인 · 물품판매 · 기타**
2. 매출 내역 탭의 `구분` 필터에서도 `회원권` 옵션 제거
3. **서버에서 항목을 검증하게 했다** — 드롭다운에서 빼는 것만으로는 부족했다.
   오래된 탭이 열려 있거나 API를 직접 부르면 `회원권` 이 그대로 들어갔다(실제로 들어가는 것을 확인).
   이제 `LEDGER_CATEGORIES[kind]` 에 없는 항목은 거부한다.

```
POST /api/ledger {"kind":"매출","category":"회원권"}
→ {"error":"'회원권'은 매출에 쓸 수 없는 항목입니다"}
```

`매출`에 지출 항목(`임대료`)을 넣는 것도, 이미 뺀 `운동복`·`체험`도 같이 막힌다.

오류 문구의 조사(은/는)는 받침 유무로 고르게 했다(`josaEunNeun`). 안 그러면 "'임대료'은" 처럼 어색해진다.

## 남은 같은 패턴 (보고만)

`락커`·`드랍인` 도 각각 락커 배정·신청 화면에서 자동으로 매출에 잡히는데 가계부 항목에도 남아 있다.
회원권과 같은 이중 계상 여지가 있지만 이번 지시 범위가 아니라 두었다.

가계부 지출의 `환불` 중복 건은 **사장님 혼자 쓰는 시스템이라 상관없다**는 사용자 판단으로 그대로 둔다.

## 확인

| 입력 | 결과 |
|---|---|
| 매출 / 회원권 | 거부 |
| 매출 / 운동복 | 거부 |
| 매출 / 체험 | 거부 |
| 매출 / 임대료 (지출 항목) | 거부 |
| 항목 비움 | "항목을 선택해주세요" |
| 매출 / 물품판매 | 통과 |
| 지출 / 공과금 | 통과 |

전 파일 문법 통과, 서버 에러 0, 연결 검사 재통과. 확인에 쓴 데이터는 전부 삭제했다.

## 추가: 락커·드랍인도 제외 (사용자 지시)

락커와 드랍인도 각자의 등록 화면에서 자동으로 매출에 잡히므로, 회원권과 같은 이유로 가계부에서 뺐다.

**가계부 매출 항목 최종: `물품판매` · `기타` 두 개.**
자동으로 안 잡히는 것만 남긴 셈이다. 매출 내역 탭의 `구분` 필터에는 `락커`·`드랍인`이 그대로 있다
(자동으로 잡힌 건을 골라 봐야 하므로 필요하다).

서버 검증도 같이 적용되어 `락커`·`드랍인`으로 직접 넣으려 하면 거부된다.
